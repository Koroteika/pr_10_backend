# 🐦 Классификация птиц — Backend API

## 📋 Описание

Данный репозиторий содержит серверную часть проекта по классификации изображений птиц. В качестве веб-фреймворка используется **FastAPI**, а модель глубокого обучения построена на базе **TensorFlow/Keras**. Сервис принимает изображение и возвращает предсказанный класс птицы и вероятности по всем классам.

**Пользователи могут:**

- 📤 Отправить изображение через POST-запрос на эндпоинт `/predict`
- 📊 Получить предсказанный класс и вероятности по всем трём классам
- ❤️ Проверить состояние сервиса через `/health`

---

## 🔬 Сравнение моделей

В рамках практических работ 2–5 были обучены и сравнены следующие модели классификации изображений:

| Модель | Accuracy | Precision | Recall | F1-мера | Время инференса (мс/img) |
|---|---|---|---|---|---|
| **CNN+BN+Dropout (ПР-4)** ✅ | **0.9315** | **0.9315** | **0.9315** | **0.9314** | 2.374 |
| CNN (ПР-3) | 0.8883 | 0.8905 | 0.8883 | 0.8878 | 1.768 |
| Dense (ПР-2) | 0.5640 | 0.5851 | 0.5640 | 0.5507 | 1.184 |
| EfficientNetB4 (ПР-5) | 0.5423 | 0.5792 | 0.5423 | 0.4776 | 30.403 |

> Лучшая модель выбрана по метрике **F1-мера** — **CNN+BN+Dropout (ПР-4)** с F1 = 0.9314. Сохранена в `best_classification_model.keras`.

## 🗂 Используемый датасет

- **Название:** Indian Birds Dataset
- **Классы (3):** Asian Green Bee-Eater, Brown-Headed Barbet, Common Kingfisher
- **Размер входного изображения:** 128×128 пикселей
- **Нормализация:** значения пикселей приводятся к диапазону [0, 1]

---

## 🛠 Используемые технологии

- **Python** 🐍: основной язык программирования
- **FastAPI** ⚡: фреймворк для создания REST API
- **TensorFlow / Keras** 🧠: загрузка и инференс модели глубокого обучения

## 📁 Структура проекта

- **`main.py`**
  Серверная часть на базе FastAPI:
  - 📥 Принимает изображение в формате `UploadFile`
  - 🔄 Выполняет предобработку (resize 128×128, нормализация)
  - 🎯 Возвращает предсказанный класс и вероятности

- **`best_classification_model.keras`**
  Сохранённая лучшая модель классификации.

- **`requirements.txt`**
  📦 Список зависимостей, необходимых для работы проекта.

## ⚙️ Установка и запуск

1. **Клонируйте репозиторий:**

   ```bash
   git clone https://github.com/Koroteika/pr_10_backend.git
   cd pr_10_backend
   ```

2. **Создайте и активируйте виртуальное окружение:**

   **На Windows:**
   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   ```

   **На macOS/Linux:**
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

3. **Установите зависимости:**

   ```bash
   pip install -r requirements.txt
   ```

4. **Запустите сервер:**

   ```bash
   uvicorn main:app --host 0.0.0.0 --port 8000
   ```

5. **Перейдите по адресу** [http://localhost:8000/docs](http://localhost:8000/docs) для интерактивной документации API.

---

## ⚙️ Как это работает

1. 🖼️ Клиент отправляет изображение POST-запросом на `/predict`
2. 🔄 Сервер открывает изображение, конвертирует в RGB, масштабирует до 128×128 и нормализует
3. 🧠 Модель выполняет инференс и возвращает вероятности по трём классам
4. 📤 API возвращает JSON с предсказанным классом, уверенностью и распределением вероятностей

## 🔌 Примеры использования API

**Через curl:**
```bash
curl -X POST "https://pr-10-backend.onrender.com/predict" \
  -F "file=@bird.jpg"
```

**Через Python:**
```python
import requests

with open("bird.jpg", "rb") as f:
    response = requests.post(
        "https://pr-10-backend.onrender.com/predict",
        files={"file": f}
    )

print(response.json())
```

**Пример ответа:**
```json
{
  "predicted_class": "Common Kingfisher",
  "confidence": 0.971234,
  "probabilities": {
    "Asian Green Bee-Eater": 0.012345,
    "Brown-Headed Barbet": 0.016421,
    "Common Kingfisher": 0.971234
  }
}
```
